What this is

これは動画ではありません。実際のハエ1匹の脳の全配線図から、 いま計算された神経活動です。

2024年、ショウジョウバエ成虫の脳の完全な配線図が公開されました。 139,255個のニューロンと約5,450万個のシナプス、そのすべての接続先と 接続強度が記録された、動物の脳としては史上初の完全なコネクトームです。

配線図があれば、脳を「回路」として動かせます。ここでは各ニューロンを leaky integrate-and-fire モデル（電気回路としての神経細胞）に置き換え、 12.7万ニューロン・1,470万接続の回路をまるごと数値積分しています。

刺激を与えなければ、この脳は1秒間に0スパイク——完全に沈黙します。 砂糖受容ニューロンをたった21個叩くだけで、約400個のニューロンが連鎖的に発火し、 口吻を伸ばす運動ニューロンMN9に到達する。上のビューアはその1秒間の記録です。

Experiment · 生きたハエではできない実験

ニューロンを1個ずつ消して、食欲のスイッチを探す

ここでやるのは、計算機のほうが得意なことではありません。 本物の脳が相手でないと意味がなく、生きている脳では実行できない実験です。

生きたハエで狙ったニューロンを黙らせるには、遺伝子操作で数か月。しかも1回の実験で 1種類しか試せません。配線図があれば、全部試せます。ここでは砂糖に反応して発火している ニューロン—個を1個ずつ消して、そのたびに回路を走らせ直しました。 同じ数の実験を実験室でやろうとすると、ハエの一生どころか研究者の一生でも足りません。

    パズル：ハエに毒を食べさせろ

    砂糖と苦味を同時に与えると、ハエは食べません。では どのニューロンを黙らせれば、毒入りの餌を食べるようになるでしょうか。

    苦味の受容ニューロン自体を切るのは反則です（味が届かないだけなので）。 中枢のニューロンだけで拒否権を無効化してください。 止める単位は「細胞タイプ」——実際のハエの遺伝子操作で狙えるのがタイプ単位だからです。 つまりここで見つけた答えは、そのまま実験室に持ち込める仮説になります。 押すたびに4,000ニューロンが走り直すので、答えは記憶ではなく実測です。

    ここから何が見えるか

    • 苦味は砂糖に勝つ — 砂糖を最大にしてから苦味を上げると、MN9は完全に停止します。 これは実際のハエの行動（苦い餌は吐き出す）と同じで、抑制性ニューロンによる回路レベルの 拒否反応が配線図だけから再現されています。
    • 応答には遅れがある — 砂糖を与えてから最初のMN9スパイクまで 25 ms、発火率が立ち上がるまで30 ms（実測）。 シナプス遅延1.8msが何段も積み重なった、回路の物理的な制約です。 逆に苦味を足すと25 msで沈黙します——拒否のほうがわずかに速い。
    • 閾値がある — 砂糖を少しずつ上げていくと、ある濃度で急にMN9が立ち上がります。 「薄い砂糖水は無視する」という判断が回路に埋め込まれています。 ①のゲームで薄い蜜を食べてくれないのはこれが理由です。

    HCIの入力装置として見ると、これは遅延と不応期と閾値を持つ、実在の生物に 由来するコントローラです。同じ操作を繰り返しても出力は揺らぎます（ポアソン入力の 確率性）。決定論的なUIとは違う手触りがあります。

    Recipes · 遊び方の例

    手元で動かすと、ブラウザ版ではできないこと——全脳12.7万ニューロンの操作、 任意のニューロンの沈黙、全スパイクの記録——ができます。

    以下はすべて実際に実行して結果を確認したものです。1試行あたり20〜40秒（全脳・1秒分）。

    1. ハエに砂糖を味わわせる

    python sim.py --stim sugar --rate 100 --trials 3 --name taste

    砂糖受容ニューロン21個を100Hzで刺激します。約400個のニューロンが発火し、 最後に MN9 rate: 82.7 Hz と表示されれば、ハエは口吻を伸ばそうとしています。

    2. 何もしないと脳は沈黙する

    python sim.py --rate 0 --trials 1 --name silence

    結果は saved 0 spikes。12.7万ニューロンが1秒間まったく発火しません。 このモデルには自発発火がなく、活動はすべて感覚入力に由来します。

    3. 苦味で摂食を止める

    python sim.py --stim sugar --rate 100 --stim2 bitter --rate2 100 \
       --trials 3 --name sugar_vs_bitter

    砂糖を与えたまま苦味受容ニューロン64個を同時に刺激すると、MN9は 82.7 Hz → 0.0 Hz。完全に沈黙します。上のインタラクティブパネルで 触れるのがこの現象です。

    4. ニューロンを黙らせる（回路の外科手術）

    python sim.py --stim sugar --rate 100 --silence type:CB0248 \
       --trials 3 --name surgery

    CB0248は砂糖応答で最も激しく発火するGABA作動性（抑制性）ニューロンで、左右に1個ずつ、 計2個あります。この2個を黙らせるとMN9は 82.7 Hz → 92.0 Hz に上がります。 ブレーキ役を外したぶん摂食の駆動が強まる——脱抑制です。 --silence はそのニューロンの出力シナプスをすべて0にします。

    5. ほかの感覚を試す

    python groups.py --list class subclass    # 使える名前の一覧
python sim.py --stim type:R1-6 --rate 30 --name light      # 光（光受容細胞1,908個）
python sim.py --stim type:ORN_DA1 --rate 50 --name pheromone  # フェロモン（嗅覚122個）
python sim.py --stim class:thermosensory --rate 50 --name heat

    光を当てると（光受容細胞1,908個を30Hzで刺激）、脳全体のスパイクは 砂糖のときの12,557個から 57,243個 へ跳ね上がります。視覚系が激しく活動する一方で、 MN9は0 Hzのまま——光ではハエは食べようとしません。 感覚のモダリティごとに届く先が違うことが、配線図だけから出てきます。

    刺激対象は sugar / bitter のような組み込み名のほか、 type:（細胞タイプ）、class:（細胞クラス）、 subclass:（サブクラス）、FlyWire IDの直接指定が使えます。 @R / @L を付ければ左右どちらかの半球に限定できます。

    6. 結果を3Dで見る

    python viz_export.py results/taste.parquet
python build_page.py     # -> docs/index.html（このページが再生成される）

    Model & validation · モデルと検証

    Shiu et al. 2024 (Nature) の leaky integrate-and-fire モデルをそのまま使っています。 オリジナルはBrian2実装ですが、ここではNumPyだけで書き直しました。

    • 静止電位 −52 mV / 閾値 −45 mV / 膜時定数 20 ms / 不応期 2.2 ms
    • シナプス: 発火の1.8 ms後に、指数減衰するコンダクタンス（τ = 5 ms）へ 0.275 mV × シナプス数を加算。GABA作動性・グルタミン酸作動性は負の重み
    • 刺激: ポアソン過程で膜電位を直接押し上げる（受容ニューロンに不応期なし）
    • 線形ODEの厳密解で0.1 msごとに更新。シナプス遅延はリングバッファで処理
